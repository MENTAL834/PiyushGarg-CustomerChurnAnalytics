## 📌 Project Overview
Customer attrition directly impacts business profitability and growth. This project implements an end-to-end Data Analytics and Machine Learning pipeline to identify at-risk customers, uncover key behavioral churn drivers, and deliver actionable retention strategies using Predictive AI.

### Objectives:
- Perform Exploratory Data Analysis (EDA) to understand demographic and account patterns.
- Handle class imbalance and feature engineering for behavioral attributes.
- Train and evaluate predictive classification models (Random Forest, Logistic Regression, XGBoost).
- Generate actionable data-driven insights and feature importance for business stakeholders.

## 📊 Dataset Link
- **Dataset:** Telco Customer Churn
- **Source:** [Kaggle - Telco Customer Churn Dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) / IBM Sample Data Sets
- **Size:** 7,043 rows, 21 columns (demographics, services, tenure, payment methods, and churn status).
